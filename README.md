CipherKey - Secure Password Generator & Strength Checker 🛡️
CipherKey is a modern, responsive, and secure web application designed to help users generate strong, random passwords and check the strength of their existing ones in real-time. The tool provides instant visual feedback and a detailed criteria checklist, all within a sleek and intuitive user interface.

✨ Features
CipherKey is packed with features to enhance password security and user experience:

🔑 Password Generator
Cryptographically Secure: Generates passwords using the window.crypto.getRandomValues() API, ensuring a high degree of randomness suitable for security-sensitive applications.

Customizable Length: Easily adjust the desired password length from 8 to 32 characters using an intuitive slider.

Guaranteed Complexity: The generation algorithm ensures that every password contains at least one uppercase letter, one lowercase letter, one number, and one special character.

One-Click Copy: A convenient button to instantly copy the generated password to the clipboard.

💪 Password Strength Checker
Real-Time Feedback: The strength bar and criteria checklist update instantly as you type.

Visual Strength Bar: A color-coded progress bar (Red for Weak, Orange for Moderate, Green for Strong) provides an immediate sense of your password's security level.

Detailed Criteria Checklist: A checklist that validates the following five essential criteria for a strong password:

At least 8 characters long :-

Contains at least one uppercase letter (A-Z)

Contains at least one lowercase letter (a-z)

Contains at least one number (0-9)

Contains at least one special character (!@#$)

Toggle Password Visibility: A handy eye icon to show or hide the password you are typing.

🛠️ Technologies Used :-
